## Context
Before writing or running C# code against Supabase, test data must be populated in the database. This allows testing the Data API directly (`test.http` or browser/curl) to verify that tables, RLS policies, and API keys are functioning properly. As stated in Slide 46: *"If this returns your rows as JSON, the database side works. Any later bug is in your C#."*

## Testing the Connection (Slide 46)
Create `database/test.http` for quick testing via VS Code REST Client or curl:

```http
@url = https://YOUR-REF.supabase.co
@key = sb_publishable_...

### Test 1: Fetch all tours
GET {{url}}/rest/v1/tours?select=*
apikey: {{key}}

### Test 2: Fetch all active bookings
GET {{url}}/rest/v1/bookings?deleted_at=is.null&select=*
apikey: {{key}}
```
